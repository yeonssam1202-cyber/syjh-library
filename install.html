휴대폰 홈 화면에 추가

한 번만 해 두면 카카오톡 아이콘처럼 한 번 눌러서 바로 열려요. 주소를 외울 필요가 없어요.

지금은 카카오톡·네이버 같은 앱 안에서 열려 있는 것 같아요.
이 상태에서는 추가가 안 돼요. 오른쪽 위(또는 아래)의 ⋮ / 공유 메뉴에서 "다른 브라우저로 열기"를 눌러 아이폰은 Safari, 안드로이드는 Chrome으로 열어 주세요.
✓ 이미 홈 화면에서 열고 계세요. 따로 할 일이 없어요!
아이폰은 꼭 Safari(사파리)로 열어야 해요. 파란 나침반 모양 앱이에요.
  1. 1
    Safari로 이 사이트를 열어요

    주소창에 yeonssam1202-cyber.github.io/syjh-library를 입력하고 로그인해요.

  2. 2
    아래 가운데 공유 버튼을 눌러요

    네모에서 화살표가 위로 나온 모양이에요.

  3. 3
    메뉴를 올려서 "홈 화면에 추가"를 눌러요

    목록이 길어서 위로 쓸어 올려야 보일 수 있어요.

  4. 4
    오른쪽 위 "추가"를 눌러요

    이름은 그대로 두셔도 돼요. 홈 화면에 작은도서관 아이콘이 생겨요.

안드로이드는 Chrome(크롬)을 권해요. 삼성 인터넷은 아래에 따로 적어 뒀어요.
  1. 1
    Chrome으로 이 사이트를 열어요

    주소창에 yeonssam1202-cyber.github.io/syjh-library를 입력하고 로그인해요.

  2. 2
    오른쪽 위 점 세 개를 눌러요

    점이 세로로 세 개 있는 모양이에요.

  3. 3
    "홈 화면에 추가" 또는 "앱 설치"를 눌러요

    휴대폰마다 이름이 조금 달라요. 둘 중 보이는 걸 누르면 돼요.

  4. 4
    "추가" 또는 "설치"를 눌러요

    한 번 더 물어보면 눌러 주세요. 홈 화면에 작은도서관 아이콘이 생겨요.

삼성 인터넷을 쓰는 경우

아래쪽 메뉴(줄 세 개) → "현재 페이지 추가" → "홈 화면" 을 차례로 눌러요.

안 될 때는

  • "홈 화면에 추가"가 안 보이면: 카카오톡·네이버 앱 안이 아닌지 확인해 주세요. 위 빨간 안내가 나오면 그 방법으로 브라우저를 바꿔요.
  • 아이콘을 눌렀는데 로그인 화면이 나오면: 한 번 로그인해 두면 계속 유지돼요.
  • 그래도 안 되면 총무나 관리자에게 알려 주세요.
